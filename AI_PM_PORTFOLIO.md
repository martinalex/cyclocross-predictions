## Output Format Specifications

### Demo (Streamlit or Video Walkthrough)
- Show pipeline flow: upload → score → report
- Highlight zero-hardcode config (registry/metadata)
- Surface key metrics panel: Hits@10/3, Spearman, MAE, confidence buckets
- Include "how it works" sidebar: features, calibration, cold-start handling

### Repo Documentation
- Concise AI PM section: problem → metric → ROI; data contract; feature rationale
- VERSION_HISTORY-style narrative: what changed, why, metric impact
- Reusable report template for new datasets

### Portfolio Page
- Three case studies (VeloPredict/VeloIntel/WellnessAI): problem, approach, iterations, metrics, lessons
- Artifact links: exec brief, data contract, validation plan, API contract
- Link to live demo and repo docs

### Medium Article
- Story arc: before/after transformation
- "Why Hits@K + Spearman/MAE" explanation
- Calibration and confidence buckets for decisioning
- Charts/tables from SEASON_TRACKER showing improvement
- Lessons learned (annotate don't exclude, cold-start penalty)

### YouTube Video
- 5-8 minutes runtime
- Intro: problem/metrics framing
- Live demo: upload → report flow
- Quick explain: features/calibration/confidence buckets
- Results snapshot: SEASON_TRACKER highlights
- Closing: next steps and use cases
- Overlay captions for key metrics
